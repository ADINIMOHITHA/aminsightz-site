Privacy information

This page describes the AM Insightz website and the current Retainer Scope Kit release candidate.

Information collected through this website

This is a static information website. It has no account registration, contact form, newsletter, analytics, advertising pixels, or embedded payment form. AM Insightz does not ask you to submit personal information through these pages.

The site is hosted with GitHub Pages. When a browser requests a web page, GitHub may process technical request information to deliver and protect its hosting service under GitHub’s own policies. AM Insightz does not operate or control GitHub’s hosting systems.

Product data

The release candidate is an offline HTML tool. Its calculator inputs and edited reply stay in the open browser page; the tool does not send them to AM Insightz or another service and does not save them automatically. Reloading or closing the page clears unsaved work. Files you choose to export are created on your device.

Optional AI prompts in the included worksheets are for use only if you choose to copy them into a separate service. Do not share client secrets or personal information with that service.

External links

This website links to GitHub for public product issue reports. If you follow that link, GitHub handles information according to its own privacy practices. Please do not place client information, private business figures, or other confidential material in a public issue.

Payments and customer data

No product is currently for sale, and this website has no checkout or payment processing. If a storefront is introduced later, the privacy information will be updated to identify the seller and explain the relevant payment and delivery processing before sales begin.

Questions

For a privacy question, use the public GitHub issue tracker. Do not post sensitive or confidential information there.

This notice reflects the current static website and offline release candidate. It must be reviewed again if analytics, forms, checkout, or other data processing is added.
